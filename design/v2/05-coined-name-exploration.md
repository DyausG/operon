# OPERON V2: Distinctive public-name exploration

Status: research and recommendation only. Nothing has been renamed. No logos or final assets were
made, and Phase 3 has not started. **OPERON stays the repository and internal codename.** That
covers the repository, Python modules, environment variables, migration identifiers, protocol
identifiers, database identifiers, tests and internal provenance identifiers.

**This is not legal advice.** It is a preliminary collision and branding screen. The checks that
still need a trademark professional are listed in §13.

Foundation:
- Phase 2.6 naming due diligence (`04-naming-due-diligence.md`, commit `7737c75`). It rated the
  OPERON collision **VERY HIGH**: a YC S26 "Operon" sells predictive maintenance into process
  plants, and US application 99703517 for OPERON is pending in class 42. It also found that plain
  dictionary words for hold, govern, verify and support are saturated by AI-agent-governance
  startups from 2025–26. Its finalists, **Detent** and **Truebearing**, both screened MODERATE.
- Phase 2.5 brand strategy (`03-brand-strategy-and-identity.md`, commit `a55a64b`). The territory
  is "Instrument & Record". The palette is Ink #0C1418, Paper #F3F4F1 and Graphite neutrals, with
  no chromatic brand hue. The type is IBM Plex Sans and Plex Mono. The tagline is "From early
  warning to verified recovery."

**Method:**
- Work done on 2026-10-05:
  - generated 134 candidates in 9 families;
  - narrowed them to 40, then 20, by internal screen;
  - ran three parallel collision-screening passes on those 20 (7 + 7 + 6);
  - re-verified DNS and the npm and PyPI registries directly for the top 10;
  - rendered a wordmark test in IBM Plex;
  - ran a product-language test;
  - scored the top 10 out of 100 against the three benchmarks.
- Evidence levels, as in 2.6:
  - **DIRECT**: queried first-hand. This covers DNS resolution, the npm and PyPI JSON registries,
    and GitHub repository search through the session's GitHub tool.
  - **SNIPPET**: a search-engine summary of a page.
  - **GK**: general knowledge, used only to eliminate names at the longlist stage and not
    re-researched.
- Most primary sites (company sites, USPTO TSDR, EUIPO/TMview, IP India, UKIPO, domain
  marketplaces) are blocked by this session's egress proxy. Company facts are therefore SNIPPET and
  must be re-checked by a person with normal web access.
- DNS caveat: **RES** means the domain resolves, so it is registered. **NX** means it does not
  resolve. NX suggests, but does not prove, that a domain is unregistered.

## 1. Why this phase

Phase 2.6 recommended keeping OPERON for now and planning a rename. The user modified that
recommendation: pick the long-term public name **before** Phase 3, so that the identity work
(wordmark, monogram, favicon, product voice) is built once, on the name that will ship.

Phase 2.6 also showed why **dictionary words** fail here:

- Holdpoint, Witness, Governor, Interlock, Countersign and Datum all collided with agent-governance
  or verification products launched in 2025–26.
- Detent and Truebearing, the best survivors, were still MODERATE, mainly because of detent.ai
  ("Proof-Carrying AI") and PyPI `detent`, and mercator-hq/truebearing (an agent-guardrails project)
  respectively.

This phase therefore leans toward **coined or modified words**, which are easier to own and to
register.

## 2. Constraints applied

| Constraint | Applied as |
|---|---|
| Length | 2–4 syllables; roughly 5–10 letters |
| Saying and spelling | One obvious pronunciation in English and Indian English. Spellable after hearing it once. |
| Banned devices | AI suffixes (-ai, -ly, -ify, -iq), .ai-style misspellings, gratuitous X/Z/Q, and the words *neural, cognitive, agent, intelligence, predict, smart, autonomous* |
| Banned registers | Factory-equipment maker, bearing company, cybersecurity, crypto, military, generic AI, CMMS clone, biotech or pharma |
| Languages | English and Hindi checked for practical problems. Major European languages checked where a pass surfaced something. Obscure foreign meanings are **not** grounds for rejection. |
| Domains | Exact .com is **not** overvalued. get-, -hq, -systems, -ops, .ai and .io were all checked. |
| Fit | Must work in the territory "Instrument & Record" and in system-voice product sentences without implying the software holds authority. Phase 2.5 rule: the agent advises, people approve, the record proves. |

## 8. Product-language test

**Rule from Phase 2.5:** the agent advises, people approve and the record proves. A name used as
the sentence subject must therefore read as a **system or instrument**, not as a person or a
higher authority. "Verified by <NAME>" is acceptable only where verification is the
deterministic recovery check. "Recorded in <NAME>" is preferred elsewhere.

### Top 3, full sentence set

| Sentence | Trevane | Stedra | Halvard |
|---|---|---|---|
| detection | Trevane detected an abnormal vibration pattern on Pump P-204. | Stedra detected an abnormal vibration pattern on Pump P-204. | Halvard detected an abnormal vibration pattern on Pump P-204. |
| recommendation | Trevane recommends inspecting the drive-end bearing. | Stedra recommends inspecting the drive-end bearing. | Halvard recommends inspecting the drive-end bearing. |
| waiting | Trevane is waiting for technician evidence. | Stedra is waiting for technician evidence. | Halvard is waiting for technician evidence. |
| gate | Trevane requires approval before execution. | Stedra requires approval before execution. | Halvard requires approval before execution. |
| verification | Verified by Trevane. | Verified by Stedra. | Verified by Halvard. |
| module | Trevane Reliability | Stedra Reliability | Halvard Reliability |
| tagline | Trevane — From early warning to verified recovery. | Stedra — From early warning to verified recovery. | Halvard — From early warning to verified recovery. |
| **Verdict** | Reads as an instrument and system throughout. "Verified by Trevane" is crisp. The tagline pairs naturally: a vane is the early-warning instrument. | Reads as a system. "Stedra Reliability" is slightly redundant (steady + reliability) but works. | **Personifies.** "Halvard recommends…" and "Halvard is waiting…" read as a named colleague or assistant. That conflicts with the rule that the software does not hold authority. |

### Rest of the top 10 (abbreviated)
- **Sorvel:** neutral; "Verified by Sorvel" is fine. It carries no meaning to reinforce the
  tagline.
- **Tallis:** "Tallis recommends…" is a surname again; mild personification.
- **Varro:** a personal name, so it personifies.
- **Moraine:** "Verified by Moraine" works, but "Moraine Reliability" carries the "debris" undertone.
- **Ergane:** mispronounced in speech.
- **Tribos:** reads as "tribes" in some markets.
- **Orrery:** "Orrery requires approval" is hard to say aloud and to spell.

Benchmarks:
- *Detent*: "Detent requires approval before execution" is the best gate sentence of any name.
- *Truebearing*: "Truebearing recommends inspecting the drive-end bearing" puts "bearing" twice in
  one sentence and reads as a bearing company.
- *OPERON*: reads well, but collides (2.6).

**Verdict: TREVANE CLEARS THE BAR.**

nothing screened LOW, and the four LOW–MODERATE names score within 4 points of each other. Trevane
